# Panel De Control - MiTeleferico

Proyecto educativo desarrollado para la materia de **Programación Web 1**. Permite simular y analizar situaciones hipotéticas de operación de un teleférico.

## Integrantes del grupo
* EDILSON BEIMAR SUCA ROMAN

## Módulos implementados
1. **Detención de emergencia:** Calcula la distancia recorrida durante el tiempo de reacción con alertas por niveles.
2. **Control de mantenimiento:** Gestiona componentes y cabinas por línea usando arreglos de objetos y `localStorage`.
3. **Viento y oscilación:** Analiza 5 mediciones obteniendo promedio, máximo y nivel de alerta.
4. **Validación de sensores:** Valida códigos mediante expresión regular (`/ ^SEN-\d{3}$ /`) y registra lecturas.

## Instrucciones de uso
Abrir el enlace de GitHub Pages o ejecutar `index.html` en cualquier navegador web moderno.
